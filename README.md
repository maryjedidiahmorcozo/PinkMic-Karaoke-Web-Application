## 💗 About PinkMic

**PinkMic** is a browser-based karaoke application designed to make singing more accessible, personal, and fun. It combines a searchable music library with YouTube karaoke playback and local MP3 audio support in a clean, responsive interface.

From Filipino OPM favorites to English pop, K-pop, R&B, and rock, PinkMic gives users a space to explore music and create their own karaoke experience.

## 🚀 Getting Started

### Requirements

- A modern web browser
- A code editor such as Visual Studio Code
- An internet connection for YouTube playback and externally hosted fonts
- MP3 files you want to play locally

### Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` directly in your browser, or launch it using the **Live Server** extension.
4. Search the song library and explore the available features.
5. Add a YouTube karaoke video or upload MP3 files to start singing.

No package installation or build process is required for this front-end version.

## 🎤 How to Use PinkMic

**Add YouTube karaoke songs**
1. Find a karaoke video on YouTube.
2. Copy its video URL.
3. Enter the song title and artist in PinkMic.
4. Select a genre and paste the URL.
5. Add the song and play it from your library.

**Play your own MP3 files**
1. Select **Choose MP3 files**.
2. Choose one or more MP3 files from your device.
3. Select a song from the library.
4. Use the player controls to play, pause, seek, and adjust volume.

**Organize your music**
- Search by title or artist.
- Filter songs by genre or source.
- Add songs to Favorites.
- Queue songs for your next karaoke session.

## ⚠️ Notes and Limitations

- Catalog entries are song information only; they do not automatically include playable audio.
- YouTube playback depends on the video URL, availability, and embedding permissions.
- Uploaded MP3 files are currently local to the browser session and are not uploaded to a server.
- Favorites are stored in the current browser; they are not synced between devices.
- PinkMic does not host copyrighted songs or karaoke videos. Users should use audio and video content they have permission to access.

## 🎀 Design Philosophy

PinkMic combines a soft pink and lavender visual identity with a simple music-first experience. The goal is to make discovering songs and starting a karaoke session feel effortless, whether you're singing OPM classics, international hits, or your current favorite song.
